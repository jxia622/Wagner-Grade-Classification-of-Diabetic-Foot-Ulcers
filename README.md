# Wagner-Grade Classification of Diabetic Foot Ulcers

Compares a ResNet50 baseline against a ViT-B/16 variant on 5-class Wagner-grade classification of diabetic foot ulcer (DFU) photographs.

The checkpoints for both model are in this link: https://drive.google.com/drive/folders/18mnIejHqSiUPxL9_R8DHOhu9CZVV1hvQ?usp=sharing

## Results

| Model | Test Accuracy | Macro-F1 |
|---|---|---|
| ResNet50 (baseline) | 81.65% | 0.753 |
| ViT-B/16 (variant) | 81.48% | 0.747 |

Both models converge to similar performance and concentrate their errors on adjacent Wagner grades (Grade 1 ↔ 2 ↔ 3). See `report.pdf` for full analysis.

## Dataset

The dataset is a curated set of 3,886 RGB diabetic foot photographs labeled with Wagner grades 0–5 by Rubitection. Grades 4 and 5 are merged into a combined "Grade 4–5" class for reporting.

The dataset is **not included in this repository** for size and licensing reasons. Place the images in the directory expected by the notebooks (the path is set at the top of each notebook — adjust as needed) and ensure the folder structure matches the per-class layout assumed by `torchvision.datasets.ImageFolder`:

```
data/
├── 0/   # Grade 0 images
├── 1/   # Grade 1 images
├── 2/   # Grade 2 images
├── 3/   # Grade 3 images
└── 4/   # Grade 4–5 images (merged)
```

Class distribution: Grade 0 (1,237), Grade 1 (479), Grade 2 (1,633), Grade 3 (287), Grade 4–5 (250).

## Reproducing the report results

The fastest path is to run `reproduce.ipynb`, which loads the saved checkpoints in `checkpoints/` and regenerates the training curves, confusion matrices, and metric tables shown in the report — no retraining required.

To retrain from scratch:

1. Open `resnet50.ipynb` and run all cells. Best checkpoint will be saved to `checkpoints/resnet50_best.pth`. Roughly 30 min on a T4.
2. Open `vit.ipynb` and run all cells. Best checkpoint will be saved to `checkpoints/vit_b16_best.pth`. Roughly 45 min on a T4.

Both notebooks use a fixed random seed; results should match the report to within run-to-run noise.

## Training configuration

Shared across both models: random 70/15/15 stratified split, weighted random sampling for class balancing, label smoothing (ε = 0.1), AdamW with cosine LR schedule, early stopping with patience 8 on validation loss.

Model-specific hyperparameters:

- **ResNet50**: ImageNet-pretrained, full fine-tune, LR 5e-5, weight decay 1e-3, dropout 0.3 on the new classification head.
- **ViT-B/16**: ImageNet-pretrained, layer-wise LR (5e-4 head / 5e-5 backbone), weight decay 0.05.

See the notebooks for the full augmentation pipeline and training loop.
